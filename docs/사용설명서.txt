AI 사용량 위젯 v1.0.1  (Claude + Codex 사용률을 트레이에서 확인)
==================================================================

■ 필요한 것
  - Windows 10 / 11 (별도 설치 프로그램 필요 없음, Windows 기본 .NET 사용)
  - 터미널에서 Claude Code(claude)를 쓰는 경우 Claude 사용률 표시
    ※ Claude 데스크탑앱(Code 탭 포함)은 사용률을 넘겨주지 않습니다 (아래 "표시 값의 출처" 참고)
  - Codex (데스크탑앱 또는 CLI) 를 쓰는 경우 Codex 사용률 표시
    둘 중 하나만 써도 됩니다.

■ 설치
  1. 압축을 풀고 AIUsageWidget.exe 를 계속 둘 폴더에 놓습니다.
     예) 문서\AIUsageWidget\AIUsageWidget.exe
     ※ 다운로드 폴더나 압축 파일 안에서 바로 실행하지 마세요.
        Claude 설정과 자동 실행에 exe 위치가 기록됩니다.
        나중에 exe를 옮겨도 다시 실행하면 경로를 스스로 고칩니다.
  2. AIUsageWidget.exe 를 실행합니다.
     "Windows의 PC 보호" 창이 나오면 [추가 정보] → [실행]을 누릅니다.
     (서명되지 않은 개인 제작 프로그램이라 나오는 경고입니다)
  3. 처음 실행하면 두 가지를 묻습니다.
     - Claude 연동: Claude Code 설정(%USERPROFILE%\.claude\settings.json)에
       상태표시줄 연동을 추가합니다. 원본은 같은 폴더에 settings.json.bak-날짜 로 백업합니다.
       이미 다른 상태표시줄을 쓰고 있으면 바꿀지 따로 묻습니다.
     - Windows 시작 시 자동 실행 여부
  4. 터미널에서 Claude Code(claude)를 쓰고 있었다면 다시 시작한 뒤 한 번 대화하면
     Claude 사용률이 표시되기 시작합니다.

■ 사용법
  - 평소에는 작업 표시줄 오른쪽 트레이에 숫자 아이콘만 있습니다.
    숫자 = Claude·Codex 5시간 사용률 중 높은 값 (초록 <70%, 주황 <90%, 빨강 90% 이상)
    아이콘이 안 보이면 트레이의 ^ (숨겨진 아이콘) 안에 있습니다. 끌어내 두면 항상 보입니다.
  - 아이콘 클릭: 창 열기 / 다른 곳 클릭 또는 Esc: 창 닫기
  - 아이콘 오른쪽 클릭 메뉴
      고정 (자동으로 닫지 않음) / 지금 새로고침 / Windows 시작 시 자동 실행
      Claude 연동 설정 / 데이터 폴더 열기 / 종료

■ 표시 값의 출처 (모두 이 PC 안의 파일만 읽습니다)
  - Claude 5시간·주간: 터미널 Claude Code가 상태표시줄에 넘겨주는 공식 사용률
      터미널 Claude 세션이 열려 있는 동안 1분마다 갱신, 값은 터미널 Claude가 마지막으로 응답을 받은 시점 기준
      Claude 데스크탑앱(Code 탭 포함)은 상태표시줄을 실행하지 않아 사용률을 남기지 않습니다.
      데스크탑앱만 쓰는 동안에는 값이 멈춰 있다가, 다음에 터미널 Claude가 응답을 받으면
      데스크탑앱 사용분까지 포함한 계정 전체 값으로 따라잡습니다.
  - Codex 5시간·주간: %USERPROFILE%\.codex\sessions 로그의 마지막 기록
      Codex를 쓸 때만 갱신
  - 초기화 시각이 지난 값은 "초기화 지남"으로 표시합니다 (지난 값을 그대로 보여주지 않음)
  - 값이 없으면 "확인필요"로 표시합니다
  - 오늘 토큰: 두 도구의 로컬 로그 합산
      입력 = 캐시 포함 전체 입력, (캐시) = 그중 캐시 읽기

■ 보안
  - 인터넷에 접속하지 않습니다. 로그인 정보(토큰)를 읽지 않습니다.
  - 로그 파일은 읽기만 합니다. 변경하는 파일은 아래 3가지뿐입니다.
      %USERPROFILE%\.claude\settings.json 의 statusLine 항목 (동의한 경우, 백업 후)
      %APPDATA%\UsageWidget\ (위젯 설정, Claude 사용률 기록)
      자동 실행 등록: HKCU\Software\Microsoft\Windows\CurrentVersion\Run 의 AIUsageWidget (동의한 경우)
  - 회사 보안 프로그램이 서명 없는 exe 실행을 막으면 IT 담당자에게 허용을 요청하세요.
  - 전체 소스와 빌드 스크립트는 GitHub 저장소에 공개되어 있습니다 (검토·직접 빌드용).

■ 제거
  1. 트레이 아이콘 오른쪽 클릭 → "Windows 시작 시 자동 실행" 해제 → 종료
  2. %USERPROFILE%\.claude\settings.json 에서 "statusLine" 항목 삭제
     (또는 settings.json.bak-날짜 백업으로 되돌리기)
  3. %APPDATA%\UsageWidget 폴더와 AIUsageWidget.exe 삭제
